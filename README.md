# Vineeth-toolkit

## Educational Website Prototype

This repository now includes a starter educational website ready for future AI chatbot integration.

### Files
- `index.html` – page structure and chatbot integration placeholder.
- `styles.css` – responsive styling.
- `script.js` – smooth scroll interaction for the learning pathways section.

### Run locally
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.
